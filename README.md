# 👩‍🍳 Chef Claudia's Restaurant English & Culinary Game
### Mallorca, Balearic Islands ☀️

An interactive educational platform designed for **Chef Claudia**, a Spanish chef based in Majorca, to master English for the international kitchen, restaurant brigade coordination, and guest table service.

---

## 🌟 What's Included

1. **Interactive English Lesson (`index.html`)**:
   - **Cooking Verbs & Heat Control**: In-depth explanations of *boiling*, *simmering*, *sautéing*, *roasting*, *grilling*, and *poaching*.
   - **Restaurant Pantry & Ingredients**: Filterable, searchable vocabulary for Mediterranean & Majorcan gastronomy (fresh produce, seafood, meats, cheeses, and olive oils).
   - **Kitchen Brigade Calls**: Safety calls (*"Behind you!"*, *"Hot pan!"*), ticket timings (*"Two minutes out, Chef!"*), and restaurant slang (*"86 on red prawns"*).
   - **3D Flip Flashcards & Practice Quiz**: Interactive self-study flashcards and scenario quizzes.
   - **Native Voice Pronunciation (🔊)**: Web Speech API integration with speed controls.

2. **Teaching Mode & Guess the Dish Game (`guess_the_dish.html`)**:
   - **📖 Step-by-Step Teaching Mode**: Walkthrough of 8 iconic dishes with ingredient chips, cooking verbs, allergen alerts, and guest roleplay scripts.
   - **🎮 Guess the Dish Game**: Image-based culinary guessing game with clues, streaks, points, and audio table pitches.
   - **High-Resolution Custom Imagery**: Includes AI-generated culinary artwork and authentic Mediterranean dish photography.

---

## 🚀 How to Run Locally

Simply clone or download this repository and open either HTML file in any modern web browser:
- Open `index.html` for the complete culinary curriculum.
- Open `guess_the_dish.html` for the interactive dish lesson and game.

No web servers, Node.js, or backend build steps are required—it runs 100% in the browser with offline audio synthesis.
